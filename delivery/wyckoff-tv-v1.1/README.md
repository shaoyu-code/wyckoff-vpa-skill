## 唯一待补的开发输入

需要一份当前实际加载的源码基线，同时包含 GMI 最新补丁与其调用的 wyckoff-vpa 引擎。源码、测试、依赖声明、模板和本地补丁标识需要保留；真实行情 workspace、凭据、浏览器配置和书籍原文件不要公开提交。

历史回执给出的 `source-snapshot-local-native-readability-20260921.5.zip` 只是定位线索；后续如有新补丁，应提供当前版本而不是强行回到该快照。另一条历史回执中的 `source-snapshot.zip` 更早，不能认为它就是最新实际版本。回执不是源码文件本身。

已经有脱敏且确认为当前的源码包时，直接私下上传该包即可，不必运行下面工具。没有现成包时，工具可辅助收集；它只读明确指定的两个 Skill 根目录，不执行项目代码，不联网，不访问 TV，不修改源文件、稳定链接、运行进程或调度。

```bash
python3 delivery/wyckoff-tv-v1.1/tools/collect_runtime_baseline.py \
  --source gmi="$HOME/.codex/skills/global-market-intelligence" \
  --source wyckoff="$HOME/.agents/skills/wyckoff-vpa" \
  --out "$PWD/Wyckoff_Current_Source_Baseline.zip"
```

以上入口来自历史记录，工具会核验路径存在，不会创建或修复入口。需要 Python 3.10+；输出必须在源码根目录之外，并且不能覆盖已有文件。工具只收集源码文本，跳过运行数据、私密文件名、二进制资料及内部软链接，并在包内记录所有排除项；因此输出不是磁盘完整镜像。静态资源、被排除但实现所需的内容应由开发阶段按清单补齐。

**敏感内容扫描只是启发式检查，不保证包里完全没有隐私。** 发现疑似密钥会整包停止，不会静默删掉关键源码继续冒称完整。分享前检查包和排除清单；工具不自动上传到 GitHub 或任何外部服务。两次稳定读取不等于操作系统级原子快照；源文件持续变化时应重新收集。
