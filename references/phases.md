# Phase A–E（只在有交易区间时标注）

| 阶段 | 发生了什么 | 没发生就不要标 |
|------|------------|----------------|
| A | 旧趋势停下：PS + 高潮 + AR + ST | 没有高潮就还在趋势里 |
| B | 箱体内建原因，多空来回 | 单边走完就不是 B |
| C | Spring 或 UT 测试 | 刺破后收不回是破位，不是 C |
| D | SOS/SOW 离开箱子，回踩 LPS/LPSY | 这是开单阶段 |
| E | 趋势走起来，箱子已是过去 | 不许提前标 E |

走到哪步标哪步。脚本不会输出阶段，阶段只由你确认事件之后写。
