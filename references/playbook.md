# 读盘到出预案

## 三大定律（只问这三个问题）

1. **供求**：这一段是谁在主动？涨时放量还是跌时放量。
2. **因果**：箱体有多宽、横了多久。原因不够深，不配做波段。
3. **努力 vs 结果**：量大有没有走出对应振幅。`vsa_residual` 与 `wave_efficiency` 是这个问题的数字版。

## 五步（威科夫原流程，改成出预案）

1. 大盘 / 更高周期方向（SPX、NDX、DXY、US30Y、油，按品种选）。
2. 品种是否与大盘同向。
3. 有没有可量的原因（TR 宽度 ≥ 约 4 ATR，且能标出高潮 + 另一边）。
4. 是否出现测试（Spring/UT）且量萎缩。
5. **触发出现才给“可以下单”**；没触发时建议是空仓 + 等待句。

## 仓位

```
风险金额 = 账户权益 × 0.5%~0.75%
仓位数量 = 风险金额 / |入场中枢 − 止损|
```

相关仓位（例如 NDX + BTC + 高贝塔科技）合计风险不超过 1.5%。
