# 从量价到预案

1. 数据审计：先核对日线/周线 `meta.json` 与 `data_quality`。
2. 结构：只有可复现上下沿、触碰和原因时才承认交易区间。
3. 事件：逐一审查候选，完整复制证据身份，拒绝误报。
4. 回测：只选择核心事件之后、量能合格且未穿越核心极值的测试。
5. 高周期：周线符号、周期和时效必须与日线绑定，方向不能对立。
6. 方案：主方案和反向预案分别写触发、入场、止损、T1/T2。
7. 风险：从独立风险配置读取账户、FX、实际产品和相关风险。
8. 校验：从原始行情重算候选、触发、RR、概率和仓位。
9. 输出：只读取哈希绑定的 `analysis.validated.json`；失败则空仓。

三大威科夫问题仍然是：谁在主动、箱体原因是否足够、努力是否得到相称结果。VSA 残差和阈值波段只用于解释这些问题，不是单独买卖信号。
