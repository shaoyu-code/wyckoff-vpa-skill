# 非空仓硬闸门

只有以下条件全部成立，主方案才可以是 `enter_long` 或 `enter_short`：

1. 日线、周线原始证据可重算，符号、周期、时效和哈希一致；
2. 数据质量合格，存在可复现箱体；
3. 活跃候选全部审查，所选核心事件和回测身份完整匹配；
4. 所选事件对是最新有效对，回测没有击穿核心极值；
5. 结构化价格与成交量触发在真实回测 K 线上成立；
6. 周线不反向且不陈旧；
7. 止损位于规范极值外 0.3–0.6 ATR；
8. 入场和 T1/T2 绑定规范区间，实际 RR(T1)≥1.6；
9. 最终合流≥6，A/B/C 预案与作废规则完整；
10. 独立风险配置、实际交易载体、乘数、FX 和仓位可执行；
11. 单笔与相关风险没有超过硬上限；
12. 没有无条件市价指令、盈利保证或虚假概率。

方向性用户输出还必须满足：

```text
validation.valid = true
validation.trade_gates_pass = true
analysis.validation_status = validated_trade
analysis.decision.ready_to_execute = true
```

任一条件不成立：主方案必须为**空仓等待**，并给出需要补齐的条件。
