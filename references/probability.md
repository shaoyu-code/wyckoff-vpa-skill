# 概率怎么打（不准装成预测机）

这不是回测胜率。数字来源只有一条：`compute_vpa.py` 的 `confluence_0_10` 映射。

```
P_low  = min(70, 34 + 3 × score)
P_high = min(72, 40 + 3.2 × score)
```

score < 6：建议空仓，P 只标“若硬开”。  
LLM 只能在脚本带上 **±4 个点**（周线共振加、事件被否决减），并写出加减原因。禁止改到 80%+。禁止引用没有样本的「历史 Spring 胜率」。

主方案 P + 预案 A P + 「结构失败/空仓」应能说圆（不必精确到 1%，但三件事要盖住）。

## 允许的 ±4 理由

| 条件 | 调整 |
|------|------|
| 事件是 Spring/UT **之后** 的缩量回测，而非当根 | +3 ~ +4 |
| 周线同向 | +3 |
| 努力 vs 结果同向 | +2 |
| 事件当根就要追 | −4 |
| 逆周线 | −4 |
| 规则未触发、纯 LLM 补的事件 | −4 |
| 宏观与结构冲突（加息预期升温却做 BTC 突破） | −3 |
