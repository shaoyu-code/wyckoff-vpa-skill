# 概率合同

概率不是回测胜率，也不是点预测。它描述：在真实触发已经成立、结构未被更新证据推翻、止损与 T1 已定义的条件下，当前结构证据对“先到 T1、后到止损”的支持程度。

最终分数由 `validate_analysis.py` 从原始证据计算：交易区间、事件序列、量能确认、真实周线、实际 RR，各 0–2。

```text
P_low  = min(70, 34 + 3 × score)
P_high = min(72, round(40 + 3.2 × score))
```

规则：

- `score < 6`：方向性方案被阻断；
- `RR(T1) < 1.6`：方向性方案被阻断；
- 数据、事件、触发、周线、几何或仓位不足：`status=unavailable`；
- 调整项由校验器从可验证条件生成，总和限制在 `-4…+4`；
- 最终上下限再次封顶 72%；
- 主方案与反向方案独立评估；
- 禁止 Agent 自填 base、adjustment、low/high；
- 禁止小数点概率、80%+、盈利保证或没有样本的历史 Spring 胜率。

标准说明：

> 未校准的结构条件概率，假设触发已确认、结构仍有效且没有重大跳空；不是历史胜率。
